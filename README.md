# Python Learning Projects

This repository contains a collection of **learning projects** in Python, Data Science, and Machine Learning.  
They were completed step by step to increase complexity to practice fundamentals and strengthen understanding through hands-on tasks.

---

## 📂 Project List (in order of complexity)

1. `python_1_guess_number` — simple number guessing game.  
2. `python_2_simple_calc` — basic calculator.  
3. `python_3_generate_password` — random password generator.  
4. `python_4_todo_list` — simple to-do list application.  
5. `python_5_weather_forecast` — fetch and display weather data from an API.  
6. `python_6_scrape_news` — news scraper project.  
7. `python_7_simple_flask_blog` — minimal blog built with Flask.  
8. `python_8_telegram_bot` — Telegram bot implementation.  
9. `python_9_data_analysis` — general data analysis practice.  
10. `data_science_1_titanic` — Titanic dataset classification (intro to ML).  
11. `data_science_2_movies` — working with a movie dataset.  
12. `data_science_3_retail` — retail sales analytics.  
13. `data_science_4_titanic_prediction` — extended Titanic survival prediction.  
14. `data_science_5_price_prediction` — regression for price forecasting.  
15. `data_science_6_image_classification` — image classification task.  
16. `data_science_7_spam_classification` — SMS spam vs. ham classification.  
17. `data_science_8_customer_segmentation` — customer segmentation using K-Means.  
18. `data_science_9_stock_price_forecasting` — stock price forecasting with ARIMA.

---

## 📝 Note
All of these projects are **educational**.  
The main purpose is to practice Python, Data Science, and Machine Learning concepts while gradually moving from simple basics to more advanced topics.
